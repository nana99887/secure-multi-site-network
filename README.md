
# Secure Multi-Site Network

## Project Overview
Designed and configured a secure simulated network connecting Dublin, London and Beijing using Cisco Packet Tracer.

The aim was to establish reliable communication between multiple locations while implementing security controls to protect network resources.

## Tools and Technologies
- Cisco Packet Tracer
- VLANs and OSPF Routing
- Access Control Lists (ACLs)
- SSH and AAA/RADIUS Authentication
- Port Security and DHCP Snooping
- SYSLOG Monitoring
- WPA2 Wireless Security

## My Contribution
- Designed the multi-site network topology.
- Configured VLANs and OSPF routing between locations.
- Implemented ACLs and authentication mechanisms.
- Configured port security, DHCP snooping and wireless security.
- Tested connectivity and network access restrictions.

## Project Outcome
- Built a simulated network connecting three locations.
- Tested network connectivity and security controls.
- Gained practical experience in network design, configuration, security and troubleshooting.
